# Publish and share Ocean Analytics

1. Extract the ZIP and open the main `index.html` first.
2. Check filters, predictions and downloads using the README checklist.
3. Create a GitHub repository named `Intern_Performance_Prediction_ML_InterneePk`.
4. Upload the contents of this project folder. Ensure `index.html`, `README.md`, `train.py`, `requirements.txt` and the folders `dist`, `data`, `reports`, `tests` are in the repository root. Preserve every filename and folder.
5. Commit the upload. The README appears on your repository page.
6. To host the interactive version with GitHub Pages, use repository **Settings → Pages**, select **Deploy from a branch**, choose your uploaded branch and **/(root)**, then save. Availability depends on your repository/account settings.
7. Wait for GitHub to report publication and use the actual URL it provides. Open it on desktop and mobile and repeat the checks. The root page forwards to `dist/index.html`.

   Publishing settings reference: [GitHub Docs — Configure a publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
8. Record a short walkthrough showing a department filter, an intern review, changed predictions and the model-quality tab. Explain the synthetic-data limitation.
9. Post your project on LinkedIn with the actual repository link and live link. Mention the appropriate Internee.pk page using LinkedIn's mention selector. Copy the published post URL.
10. Paste the actual links into the fields shown in your internship submission portal. Use the correct task number from the portal; it was not supplied in the brief for this ML task.
